# PyCharm 使用说明

当前界面为高 DPI 海洋主题版本，标题统一为“海鲜鲜度倒计时”，不再使用可能显示模糊或错形的系统 Emoji。鱼、虾、蟹、贝均使用清晰的中文彩色标识，并支持窗口缩放。

## 第一次运行

1. 用 PyCharm 打开整个 `python_app` 文件夹。
2. 选择 Python 3.10 或更新版本的解释器。
3. 在 PyCharm 终端运行：`python -m pip install -r requirements.txt`。
4. 运行根目录中的 `app.py`。

也可以先双击“安装依赖.bat”，以后双击“启动程序.bat”。

## 比赛现场先这样验证

1. 不插硬件，点“开始演示”。程序会自动建立鱼、虾、蟹三张标签。
2. 演示依次在 4°C、14°C、24°C 左右各停 10 秒，之后保持在 34°C 左右。读数带 ±1°C 以内的噪声。
3. 演示模式时间加速为 1200 倍，界面会明确标注，不能与真实监测混淆。
4. 点“测试语音”检查电脑扬声器。

## 接真实 RF Nano

1. 把接收端 RF Nano 插入电脑 USB，并烧录 `02_电脑温度接收端_RF-Nano.mix`。
2. 发送端烧录 `01_泡沫箱温度发送端_RF-Nano.mix`，接好 DS18B20。
3. 打开程序，在右上角选择新出现的 COM 口，点“连接接收器”。波特率固定为 9600。
4. 用草料二维码制作并扫描如 `SEAFOOD|FISH|BOX01|F001` 的二维码。

## 模块说明

- `protocol.py`：RF 数据与二维码协议。
- `models.py`：Q10 鲜度模型、超温累计和箱/产品状态。
- `serial_worker.py`：串口后台读取。
- `camera.py`：0 号摄像头扫码。
- `voice.py`：离线语音队列。
- `simulator.py`：无硬件演示温度。
- `storage.py`：断电保存 JSON 数据。
- `ui.py`：Q 版海鲜管理界面和趋势图。

## 二维码格式

固定为：`SEAFOOD|品种|箱号|产品编号`

- 品种：`FISH`、`SHRIMP`、`CRAB`、`SHELL`
- 示例：`SEAFOOD|SHRIMP|BOX01|S001`
- 同一泡沫箱中的多个产品使用同一个箱号，温度节点发送同一个箱号。

## 重要说明

目前 24–48 小时的基准时长是科创演示初始值。正式实验时，应使用相同种类海鲜，在不同温度下做多组观测，再把 `fresh_tag/config.py` 中的 `base_hours` 替换成实验得到的数值。本系统不是食品检验仪器。
