# 接线与安装说明

## 最优安装结构

把“传感器探头”和“电子主机”分开：防水 DS18B20 探头进入泡沫箱，RF Nano、扩展板和 5V 移动电源全部装在 3D 打印盒中，并用魔术贴固定在泡沫箱外壁。整个节点跟着泡沫箱移动。

这既满足温度随海鲜移动，也避免主板长期处在冷凝水、盐水和低温环境中。探头线经过 M10/M12 防水电缆接头，留出滴水弯后再进入电子盒。

## DS18B20 三线接法

| 探头常见线色 | RF Nano 扩展板 | 说明 |
|---|---|---|
| 红 | 5V | 电源 |
| 黑 | GND | 地 |
| 黄/白 | D4 | 1-Wire 数据 |
| 4.7kΩ 电阻 | D4 与 5V 之间 | 必须的上拉电阻 |

不同厂家线色可能不一致，第一次通电前必须看卖家的定义。不要只靠颜色猜。

RF Nano 的无线芯片已集成在板上，不需要再外接 nRF24L01。发送端通过成品 5V 移动电源和 USB 线供电；电脑端 RF Nano 直接插电脑 USB。不要同时从 USB 和扩展板的另一电源口重复供电。

## 探头应该放在哪里

1. 把探头装进可清洗、带孔的食品级小保护套，不要直接刺进海鲜。
2. 固定在海鲜/包装的中部高度，离箱壁、箱盖和冰袋至少约 3–5cm。
3. 不要让金属探头紧贴冰袋，否则测到的是冰袋温度；也不要悬在箱盖上方，否则只测到上层空气。
4. 海鲜在箱内频繁换位时，把保护套夹在内篮或产品周转袋上，让探头与这一批产品一起移动。
5. 产品换到另一只泡沫箱时，在电脑端重新扫一张含新箱号的二维码；程序会把该产品绑定到新温度节点。

只有一个探头时，最佳监测对象是“这一箱/这一批海鲜的微环境”，不是某一条鱼内部的核心温度。若同箱上下温差是研究重点，可以后续在同一 D4 总线上增加第二个 DS18B20，再比较上层和中层温度。

## 3D 打印盒

打开 `海鲜温度节点外壳_可调参数.scad`：

1. 用卡尺量扩展板、移动电源、USB 插头实际尺寸。
2. 修改文件最上方 `board_x`、`board_y`、孔距、`battery_x`、`battery_y` 等参数。
3. OpenSCAD 按 F6 渲染，分别导出底盒和上盖 STL。
4. 推荐 PETG，0.2mm 层高，4 圈外墙，20% 填充；上盖朝平面打印。
5. 先打印 5–10mm 高的尺寸测试片，确认 USB 槽、线孔和板孔后再打印完整件。

这个盒是防溅设计思路，不是经过认证的防水盒。电子盒安装在泡沫箱外侧、接口朝下，比赛后擦干并取出移动电源充电。
