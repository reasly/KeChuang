# 从这里开始

1. 先看 `具体方案与比赛说明.md`，了解完整结构和答辩逻辑。
2. Mixly 先烧录 `mixly` 文件夹里的发送端和接收端。
3. 按 `hardware/接线与安装说明.md` 接 DS18B20，并打印可调参数外壳。
4. 进入 `python_app`，先双击 `安装依赖.bat`（安装本地便携 Python 到 `runtime\`），再双击 `启动程序.bat`。
5. 没有硬件时先点“演示模式”；硬件通了再用 `qr` 模板制作草料二维码。

说明：启动程序只使用 `python_app/runtime/python.exe`，不依赖系统安装的 Python。
